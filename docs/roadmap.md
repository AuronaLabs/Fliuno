## 0.0.3 开发中

- [x] AG-UI 审批重连从同一 SQLite 快照读取运行绑定、执行段边界和水位。已结束的执行段限制在本段内，并保留旧服务回退路径。

- [x] 审批续跑先通过待批索引和执行段边界核对审批身份，再解码完整任务；旧运行不能接管后续执行段的待批操作。

- [x] 宿主可只读查询任务能否恢复。查询跳过正文，只解码判断所需字段，与真正恢复共用规则，能区分模型结果未知、次数耗尽、工具结果未知及 Agent 注册问题。

- [x] AG-UI HTTP 宿主可指定模型尝试上限，连续流和审批中断两种模式共用持久限额。旧服务缺少能力时拒绝提交。

- [x] 模型任务可限制尝试次数，重启和有键重试沿用原上限。最后一次已提议且获准的工具仍可执行；次数耗尽后拒绝多发请求，并保留结果不明的记录。

- [x] 会话和工作区搜索可协商每页扫描预算，从小窗口到 512 条历史。Rust 客户端保留预算和水位，空结果页可跨重启续读。

- [x] 历史检索借用 SQLite 行，只解析用户与助手消息的匹配字段；按关键词构建上下文时才读取命中项的完整投影。无数据库迁移。

- [x] 批量核对持久审批决定：按任务与审批 ID 对齐，保留空位和重复项，单次读取与同一事件水位绑定。

- [x] AG-UI HTTP 路由支持按授权会话提交文本任务，输出 SSE 并按原运行 ID 续传。
- [x] AG-UI HTTP 合并空闲 SSE 流的任务水位查询，无关提交不会触发这些流读取空事件页。

- [x] 可选的 AG-UI 审批中断在当前运行结束后，以独立审批授权启动子运行。绑定可跨重启去重，旧运行的游标和控制权不会进入子运行。

- [x] 审批中断模式的 HTTP 重连通过索引定位游标，直接读取对应事件；跨执行段游标在读取任何事件页之前拒绝。

- [x] Rust 客户端可提交 AG-UI 文本任务，按运行 ID 查回同一任务。SSE 订阅按页回放，再根据实时水位继续输出。

- [x] `events/setScope` 可选水位通知，多次匹配提交合并为最新序号。内核按需为完整事件订阅构造正文，保留完整事件队列的缺口机制。

- [x] Rust 客户端可将实时事件通知合并为水位，按范围翻页，并在队列溢出后从已交付位置补齐。

- [x] AG-UI 输出支持 SSE，客户端可按单条消息 ID 续传。真实进程测试覆盖从历史回放接上实时通知以及跨重启续传。

- [x] 本机客户端按固定完成水位分页读取精简会话历史。每页限制条数和 JSON 字节数，超限单条保留任务引用。

- [x] Rust 客户端将持久任务事件转换为 AG-UI 运行、文本和自定义事件。重放时使用稳定的运行和消息 ID。

- [x] Rust 客户端可保存会话及工作区历史搜索游标。搜索命中可用 `session/getHistoryTurn` 在同一水位直接读取。

- [x] `events/listModelUsage` 按任务直接读取模型用量，支持有界分页和持久回放游标。SQLite v37 为旧事件回填索引。

- [x] `events/listSessionModelUsage` 与 `events/listWorkspaceModelUsage` 按范围直接读取用量。SQLite v40 迁移旧用量索引；Rust 客户端能按固定事件水位续读。

- [x] `modelUsage/getSummary` 一次读取任务、会话或工作区精确累计用量和事件水位。SQLite v43 根据已索引的报告回填固定大小计数。
- [x] `modelUsage/getSummaries` 批量读取混合范围的累计值，保留输入位置，统一事件水位，无需迁移。

- [x] `approval/listPendingSnapshot` 固定待审批收件箱的事件水位和到期时间，支持范围分页、跨重启续读及事件回放交接。

- [x] `work/getSnapshot` 一次读取同一事件水位的任务状态计数与待审批首页。SQLite v42 回填状态计数，Rust 客户端返回已定位到下一页的审批游标。

- [x] `work/subscribe` 一次读取工作台快照并建立同范围的水位订阅。Rust 客户端从同一快照分开续读审批与实时事件，溢出后按原范围补读。
- [x] 工作台快照可在同一事件水位预览最近创建的任务摘要。支持全局、工作区和会话，沿用现有索引，无需迁移数据库。

- [x] `task/getSummaries` 按 ID 批量读取指定范围的当前摘要与同一事件水位，无需重拉任务清单。Rust 客户端验证响应位置和会话范围。
- [x] 会话和工作区任务摘要均可按创建顺序倒序翻页。Rust 宿主可保存完整查询并在服务重启后按原范围、筛选和顺序续读。

- [x] `task/cancelBatch` 按显式会话或工作区原子取消选定任务，事务后通知执行器；响应丢失时可原样重试。

- [x] `events/listTaskChanges` 按现有事件索引回放变动任务，每页去重和固定水位，不读取正文；Rust 工作台订阅可使用同一个游标直接读取。

- [x] `events/listTaskSummaryChanges` 在一个 SQLite 读快照内找出变动任务并读取当前摘要，Rust 客户端区分已消费游标与摘要水位。

- [x] `events/listTaskSummaryRevisions` 按实际摘要修订回放。SQLite v45 无需历史回扫；客户端可沿用先前的事件游标，并跨越升级边界继续读取。

- [x] `artifacts/digest` 读取持久 SHA-256；旧产物按需补算，不增加启动扫描或改动目录游标，Rust 下载客户端继续验证实际字节。

- [x] Rust 客户端可凭同一产物身份和固定摘要继续写入暂存文件。重启后只读缺失字节，最后校验整个文件。

- [x] `artifacts/subscribe` 一次返回目录首页并建立同范围的事件订阅。Rust 客户端可分别保存目录快照请求和实时事件游标。

- [x] `artifacts/getDigests` 按请求顺序批量读取交付物校验摘要，区分旧产物未记录和产物不存在；全程只读元数据。

- [x] Rust 客户端可从持久字节游标续订终端输出，校验终端归属、范围和保留窗口缺口。

- [x] `session/list` 支持按创建顺序倒序读取最近会话，可叠加归档筛选。Rust 客户端可保存续页请求，重启后从同一位置继续。

- [x] `task/startSummary` 使用持久回执校验新任务的重复请求，不读取完整任务快照。SQLite v44 保留旧键的校验方式，无需回填历史正文。

- [x] Rust 客户端可分块下载产物，验证偏移、总长度和 SHA-256。类型化响应直接从帧解码。

- [x] 已批准的工作区文件可导入为二进制产物。模型收到引用和摘要，客户端可在重启后分块下载。

- [x] `approval/getDecision` 按任务和审批 ID 查回已提交的决定事件。SQLite v34 回填原始事件关联，方便连接中断后核对。

- [x] 事件回放达到条数或字节目标后只探测下一行是否存在，延后解析下一页正文并保留回放游标。

- [x] `workspace/searchHistory` 可跨会话搜索已完成任务，返回所属会话及完成序号；SQLite v33 回填工作区索引，分页复用现有历史水位和扫描预算。

- [x] Gemini Interactions 接入模型适配层，支持无状态函数续轮、逐次审批、SSE 文本预览、完整 JSON 回退及本地上下文预算。已通过回环与 app-server 进程测试，真实供应商验收待做。

- [x] 会话可在单个 SQLite 事务中批量归档或恢复，最多 32 项，任一校验或写入失败全部回滚。

- [x] 产物分块下载可按任务和产物 ID 查询正文的 SHA-256 与字节长度。
- [x] 独立审批的二进制产物创建，原始 BLOB、元数据标记、分块读取和 SHA-256 跨重启保留。文本产物保持原有格式。

- [x] 远端核对支持按任务 ID 和核对 ID 读取原始持久事件，SQLite v29 回填历史关联。

- [x] MCP 一次审批可监听最多 8 个明确列出的资源 URI，收到首条更新后返回相应 URI。

- [x] 远端状态核对由单独的有界队列处理，模型、工具和 Agent 执行继续使用自己的线程池。

- [x] 客户端可以按 Agent ID 查询 A2A 核对、订阅、续接及 ACP 会话续接能力。
- [x] 显式开启的可信 ACP 注册可在独立后台工作器中按页读取保存的会话目录；对端长时间未响应时，本地 RPC 可继续处理其他请求。

- [x] 完整任务列表支持按 JSON 字节目标分页，兼容原有列表游标和摘要查询。

- [x] 会话与工作区任务摘要清单支持 JSON 字节目标分页，保留状态筛选和任务游标。

- [x] 待审批收件箱支持 JSON 字节目标分页，按原 workspace/session 范围跨重启续读。

- [x] 会话历史检索可按用户或助手消息筛选，并沿用会话快照和分页游标。

- [x] `events/listWorkspace` 可在工作区内跨会话回放持久事件，保留全局游标、上界和每页字节目标。SQLite v27 回填索引。`events/setScope` 可订阅同一工作区的实时事件，断流后保留范围。
- [x] `events/setScope` 可订阅单个任务。`events/list` 支持包含式上界，可用同一全局序号补齐历史和实时通知。
- [x] `workspace_stat` 可在审批后查询文件类型、字节数和修改时间，适用于超过正文读取上限的文件。
- [x] `workspace_sha256` 经审批以固定大小缓冲区计算至多 64 MiB 文件的 SHA-256，返回摘要和字节数。
- [x] `workspace/get` 能由已保存的工作区 ID 查回根目录记录，包括原目录暂不可用的情况。

- [x] A2A 远程状态核对：显式查询已绑定身份，结果追加到持久事件，真实 app-server 验证重启回放、冲突与超时。
- [x] A2A 远程多轮继续：补答暂停任务或在原上下文发起新一轮；每轮独立持久化、后台复核身份与状态、发送边界可审计，重启不重发。
- [x] OpenAI/Anthropic 可选本机预算预检：整份请求按 JSON 字节估算，扣除输出预留，超预算在发送前拒绝。

## 不混淆的测试层次

- 单元测试：状态迁移、审批绑定、预算、输入校验、供应商响应解析。
- 集成测试：真实 SQLite、重启和锁；本机 HTTP fixture 验证请求与工具回传。
- 进程测试：启动真正的 app-server，通过 stdio 完成任务和恢复。
- 协议测试：MCP stdio 与 Streamable HTTP discover/initialize、JSON/SSE、标准头、工具调用和拒绝无效参数；ACP v1 会话、通知、权限、取消及输入边界；A2A 1.0 JSON-RPC 关联、Part/状态/身份、卡片固定接口、取消证据与未知结果恢复。
- 隔离测试：先运行无隔离的成功对照，再检查真实子进程的令牌/过滤器、文件/TCP 访问拒绝、空白环境、管道/参数和平台回收。Windows 主机与 Debian Linux 来宾都已运行实际行为探针。
- CI：Windows 和 Linux 编译、rustfmt、Clippy、cargo test --all-features --locked，包含显式测试服务器。

真实模型测试必须显式开启，不能在普通测试或 CI 中隐式产生付费请求。尚未用真实模型凭据验收的部分应在交付记录中明确说明。
