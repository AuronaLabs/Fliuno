# 0.0.11 至 0.0.13 · 终端工作台

[路线图](roadmap.md) · [终端指南](workbench.md) · [工程验收](execution-evidence.md)

三版按每天使用工作台的顺序推进。先补齐任务浏览，再重构日常操作和配置，最后把重启、对账和备份接入工作台。

| 版本 | 工作流 | 验收 |
| --- | --- | --- |
| 0.0.11 | 会话任务浏览可按状态翻页，打开最近列表之外的任务。调整工作区标题、任务列表、草稿、命令和审批的排版，使窄屏仍能找到提交、允许和拒绝。 | 真实终端打开旧任务、切换状态、翻页、审批及恢复布局。截图覆盖宽屏、窄屏和审批。 |
| 0.0.12 | 重构终端界面和组件。主页以当前对话与输入为主，任务历史和操作详情按需打开。使用 `~/.fliuno` 管理配置、凭据引用和本地状态。提交前可预览历史、切换隔离模式和记忆注入，选项随任务或队列保存。 | 检查首次启动、对话、草稿、审批、历史和上下文在三种常用宽度下的实际截图。验证文件配置和现有用户状态升级，验证上下文入队及重启。 |
| 0.0.13 | 在终端处理可恢复任务和未知结果，接入明确的对账和一致性备份流程。改进跨重启的工作台入口和状态反馈。 | 恢复使用原任务，对账不触发重放，备份可打开并保留已提交工作。截图覆盖恢复、对账和备份状态。 |

## 0.0.12 的重构范围

- 拆开页头、对话、输入、状态提示和按需打开的面板。首屏聚焦对话内容与下一步输入，工具和审批状态在对话中显示。让常用操作在窄终端有固定、可读的位置。
- 以用户目录的 `config.toml` 管理模型、主题、路径和 Provider 选项。密钥通过独立的本地凭据引用加载。命令行参数可覆盖本次调用，日志和界面只显示连接所需的状态。明确现有数据库的迁移与查找规则。
- 上下文预览汇报历史范围和实际会采用的设置。自动检索记忆在任务开始时选取。面板说明这一时序，并让用户从任务详情查看最终归因。

每版继续用 Windows ConPTY 和 Debian PTY 跑实际程序，发布前复查协议 Schema、旧数据库和发行包。截图从终端实际输出生成，优先覆盖长标题、中文和窗口缩小时的可读性。
